## ysynk 0.5.4

### Security and reliability

- Changing the restic executable now opens a native file picker. The desktop accepts the file you select and checks that your configuration is still current before saving it. Existing installations keep their configured executable. Restart ysynk after selecting a different one.
- Linux startup settings now identify a login entry that points to another installation. If you moved an archive, Settings explains how to register the new location and preserves the old entry for inspection.
- Scheduled backups now select a due profile and start its job under the same lock. Disabling a schedule can no longer slip between those steps.
- Desktop notifications track newly completed jobs without serializing file listings and console history every second. A job that finishes immediately after startup can now trigger a notification.
- The dependency scanner now rejects incomplete npm package records and verifies linked packages against their local manifests. The scan covered 575 locked packages. Five packages carry maintenance warnings and one retains a version match covered by the verified GLib backport. [Dependency details](https://github.com/qvga/ysynk/blob/v0.5.4/docs/DEPENDENCIES.md)

### Downloads

- `ysynk_0.5.4_amd64.deb` for Debian and Ubuntu.
- `ysynk-0.5.4-linux-x86_64.tar.gz` for a manual installation, including the launcher helper and license notices.
- `SHA256SUMS` to verify both downloads with `sha256sum --check SHA256SUMS`.

Both distributions require Linux x86-64, restic 0.17.1 or newer, GTK3, WebKitGTK 4.1, AppIndicator and a persistent Secret Service keychain. The binary assets are unsigned.

### Verification

All 42 Rust workspace tests, 23 frontend tests and 22 Python tooling tests passed. Checks also covered strict Clippy, Rust formatting, Svelte diagnostics, vendored dependency regressions and the Debian package build. The bundled UI passed browser checks at 1120×800 and 720×580. Native picker cancellation and selection were exercised in an isolated Linux desktop session using the debug build. Live remote backends and a production keychain were outside this release test.
