## ysynk 0.5.2

### Live command output

- Replaces the progress bar with scrolling restic activity and diagnostics,
  including backup file activity and processed file/byte counts.
- Enables periodic restic status updates when output is piped to the app.
- Follows new lines automatically. Scroll up to pause, then select **Follow
  output** to return to the latest lines. Cancellation remains available.
- Keeps recent output in operation history for the current session only. The
  tail is limited to 200 lines / 64 KiB, with 1,024 bytes per displayed line.
  Repository passwords are filtered before display; logs are not saved to disk.

### Linux desktop integration

- Adds an optional user-local launcher registration helper for development
  checkouts and extracted archives, so GNOME can associate the window with the
  ysynk shield icon. Debian packages already include desktop integration.
- Refuses to replace unrecognized existing user-local launchers.

### Other fixes since 0.5.1

- Tightens repository credential binding and URL validation, job admission,
  scheduler retries, and recovery after persistence errors.
- Bounds cancellation and subprocess-pipe draining, including when detached
  helpers keep pipes open after the main process exits.
- Strengthens restore and password-export destination handling. Failed or
  cancelled restore output remains available for inspection, not overwritten.
- Keeps retention previews scoped, expiring and single-use, and handles empty
  repositories and replacement previews.
- Fixes stale job completion handling, recovery when results leave retained
  history, restore-dialog dismissal, and literal path whitespace preservation.
- Includes documented GLib and deepmerge source backports and GLib compiler
  warning cleanup. Raw dependency advisory findings remain visible.

### Downloads

- `ysynk_0.5.2_amd64.deb`: Debian/Ubuntu package.
- `ysynk-0.5.2-linux-x86_64.tar.gz`: executable, desktop registration helper,
  icon and license notices; requires the same system dependencies as the package.
- `SHA256SUMS`: SHA-256 checksums for both assets.

Linux x86-64 only. Requires restic 0.17.1+, GTK3, WebKitGTK 4.1, AppIndicator and
a persistent Secret Service keychain. Assets are unsigned. Password exports are
plaintext. Keep an extracted archive at the path used for desktop registration
and autostart; repeat setup if it moves.

Known dependency findings and platform limitations remain documented in
`docs/DEPENDENCIES.md` and `docs/SECURITY.md`. These changes do not constitute a
clean-advisory claim or an independent security audit.

Verification includes Rust workspace tests and strict Clippy, frontend checks,
Python tooling tests, source-backport checks, and Linux packaging. Browser
regressions exercised the output panel at 1120×800 and 720×580, including
follow/pause, keyboard navigation, literal-text rendering and cancellation
history. Restic integration tests use temporary repositories and injected
credentials, not the user's keychain. Live remote backends, macOS/Windows and a
real desktop logout/login cycle remain unverified.
