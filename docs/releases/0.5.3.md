## ysynk 0.5.3

### Snapshot details

- Selecting a snapshot now displays available backup statistics alongside the
  restore controls: data and files processed, new/changed/unchanged files,
  uncompressed and compressed data added, and backup duration.
- Shows the snapshot's host, source paths and tags. Selection uses the already
  loaded snapshot metadata without an additional repository query.
- Older snapshots without statistics show an explicit note. Missing or invalid
  statistics are omitted, while reported zero counts remain visible.
- Statistics describe the backup when it was created; data added is not the
  snapshot's restore size or current repository usage.

### Downloads

- `ysynk_0.5.3_amd64.deb`: Debian/Ubuntu package.
- `ysynk-0.5.3-linux-x86_64.tar.gz`: executable, desktop registration helper,
  icon and license notices; requires the same system dependencies as the package.
- `SHA256SUMS`: SHA-256 checksums for both assets.

Linux x86-64 only. Requires restic 0.17.1+, GTK3, WebKitGTK 4.1, AppIndicator and
a persistent Secret Service keychain. Assets are unsigned. Password exports are
plaintext. Keep an extracted archive at the path used for desktop registration
and autostart; repeat setup if it moves.

Known dependency findings and platform limitations remain documented in
`docs/DEPENDENCIES.md` and `docs/SECURITY.md`. This release does not constitute a
clean-advisory claim or an independent security audit.

Verification: 40 Rust workspace tests, strict Clippy, Rust formatting, 23 frontend
tests, frontend type checks and dependency regressions, 20 Python tooling tests,
source-backport checks, and Linux package build passed. Browser checks used the
real bundled UI with mock snapshot data at 1120×800 and 720×580, including
selection changes and snapshots without statistics. No browser console errors
or failed requests were observed. Native keychain integration and live remote
backends were not tested for this release. The advisory scan retains the same
six documented package findings as 0.5.2.
